# 哈基米桌面宠物使用指南 - 优化版

## 🎉 最新优化功能！

### ✅ 已完成的三大优化：

1. **对话框关闭优化** - 关闭功能弹窗不会影响桌面宠物主程序
2. **摄像头调用优化** - 启动时不调用摄像头，只有手动开启隐私保护时才启用
3. **出行规划增强** - 支持自然语言生成和Markdown导出

## 🎮 使用方法

### 1. 基本操作
- **双击哈基米** - 打开聊天对话框
- **右键哈基米** - 显示功能菜单
- **拖拽哈基米** - 移动到任意位置
- **系统托盘图标** - 快速访问所有功能
- **关闭对话框** - 只关闭弹窗，不影响主程序运行 ✨

### 2. 聊天功能 💬
点击"和哈基米聊天"后，你会看到：
- 聊天记录区域（显示对话历史）
- 消息输入框
- 发送按钮
- 快捷功能按钮

**使用示例：**
```
你: 你好哈基米！
哈基米: 你好！我是哈基米，你的桌面小助手！有什么可以帮你的吗？

你: 明天下午2点开会
哈基米: 好的！我已经帮你记录了任务：明天下午2点开会
⏰ 提醒时间：2026-01-24 14:00

你: 我想去北京玩3天，预算2000元，喜欢历史和美食
哈基米: 想去北京玩呀！我来帮你规划一下行程～
```

### 3. 任务管理 📝
点击"任务管理"后，你会看到：
- 任务列表（显示所有待办任务）
- 添加任务按钮
- 完成/删除任务按钮
- 刷新按钮

**功能特点：**
- 自然语言任务解析
- 自动时间识别
- 优先级设置
- 任务提醒

### 4. 出行规划 ✈️ (全新增强)
点击"出行规划"后，你会看到：
- 出行需求输入表单
- 生成方案按钮
- 方案展示区域
- 保存/导出功能

**✨ 新功能特点：**
- **智能自然语言解析** - 自动识别目的地、预算、天数、偏好
- **详细行程描述** - 生成自然语言的详细行程说明
- **Markdown导出** - 支持导出为格式化的Markdown文件
- **自由选择导出位置** - 可以选择任意位置保存文件

**使用步骤：**
1. 输入目的地（如：北京、上海、杭州）
2. 设置预算和天数
3. 填写偏好（如：美食、历史、自然风光）
4. 点击"生成行程方案"
5. 查看生成的多套方案（包含详细的自然语言描述）
6. 点击"导出方案"选择保存位置，导出为Markdown文件

**自然语言输入示例：**
```
"我想去北京玩3天，预算2000元，喜欢历史和美食"
"上海2日游，1500元预算"
"杭州一日游，500元，喜欢自然风光"
```

### 5. 隐私保护 🔒 (优化版)
- **启动优化** - 程序启动时不会自动调用摄像头 ✨
- **手动启用** - 只有在右键菜单中手动开启时才调用摄像头
- **自动检测** - 开启后自动人脸检测，离开30秒后激活隐私模式
- **手动控制** - 可随时手动开关隐私保护
