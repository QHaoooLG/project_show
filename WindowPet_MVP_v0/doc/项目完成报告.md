```

│   ├── privacy_guard.py       # ✅ 隐私保护器

├── ui/                 # 用户界面层
│   ├── desktop_pet.py         # ✅ 桌面宠物主界面
│   └── dialogs.py             # ✅ 功能对话框

    ├── database.py            # ✅ 数据库管理
```

## 🚀 部署和使用

### 快速启动
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 测试模块
python test_app.py

# 3. 功能演示
python demo.py

# 4. 启动应用
python start.py
```

1. **任务管理**: 在聊天框输入"明天下午2点开会"

3. **隐私保护**: 自动检测用户离开并锁屏
4. **日常聊天**: 双击哈基米进行对话交互
