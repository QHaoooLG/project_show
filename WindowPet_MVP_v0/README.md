# 哈基米桌面宠物 MVP

## 🎯 项目简介

哈基米桌面宠物是一个基于"全链路自我验证"理念的桌面智能助手，专注于解决数字化办公场景下的核心痛点：

- **事务管理混乱** → 30秒内完成任务记录
- **隐私安全担忧** → 离开工位时自动保护隐私  
- **决策疲劳** → 10分钟内生成可执行的出行方案

## 🚀 快速开始

### 环境要求
- Python 3.8+
- Windows 10+ / macOS 10.14+ / Ubuntu 18.04+
- 摄像头设备（用于隐私保护功能）

### 安装和运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 测试模块
python test/test_app.py

# 3. 功能演示
python test/demo.py

# 4. 启动应用
python start.py
# 或者
python main.py
```

## ✨ 核心功能

### 1. 智能事务管理 📝
- 自然语言任务输入（如"明天下午2点开会"）
- 智能时间解析和优先级判断
- 自动提醒和任务跟踪

### 2. 自动隐私保护 🔒
- 人脸检测技术监控用户状态
- 离开工位时自动锁屏保护
- 用户返回时自动解锁

### 3. 快速出行规划 ✈️
- 输入目的地、预算、天数即可
- 10分钟内生成2套完整出行方案
- 包含景点推荐、住宿、美食、交通

### 4. 桌面陪伴交互 💬
- 可爱的哈基米形象在桌面活动
- 智能对话和情感支持
- 右键菜单快速访问功能

## 🎮 使用方法

1. **启动应用**：运行 `python start.py`
2. **基本操作**：
   - 双击哈基米打开聊天对话框
   - 右键哈基米显示功能菜单
   - 拖拽哈基米移动到任意位置
3. **功能访问**：系统托盘图标提供快速访问
