本项目是一个基于 Python 开发的**桌面智能宠物（Desktop Pet）MVP 版本**。它不仅仅是一个可爱的桌面装饰，更是一个集成了 AI 交互、隐私保护与事务管理的数字化办公助手。

---

## 项目概述

本项目基于**“全链路自我验证”**理念构建，旨在解决数字化办公场景下的核心痛点：
1.  **事务管理混乱**：通过自然语言快速记录任务。
2.  **隐私安全担忧**：利用摄像头检测用户状态，离座自动锁屏。
3.  **决策疲劳**：提供快速的出行规划与智能建议。

项目采用模块化设计，核心代码分离清晰，便于后续功能扩展。

## 核心功能

### 1. 智能事务管理
- **自然语言输入**：支持如“明天下午2点开会”的语义解析。
- **优先级判断**：自动分析任务紧急程度。
- **实时提醒**：桌面端任务跟踪与提醒。

### 2. 自动隐私保护
- **人脸检测**：实时监控用户在工位的状态。
- **智能锁屏**：检测到用户离开座位时，自动触发锁屏保护隐私。
- **自动解锁**：用户返回时识别并自动解锁（需配合人脸识别配置）。

### 3. 桌面陪伴交互
- **哈基米形象**：可爱的宠物形象在桌面自由活动或跟随鼠标。
- **情感支持**：基础的情感对话与反馈。
- **交互操作**：支持拖拽移动、右键菜单呼出功能。

### 4. 出行规划助手
- **方案生成**：输入目的地、预算、天数，10分钟内生成可执行的出行方案。
- **内容涵盖**：景点、住宿、美食、交通一体化推荐。

## 环境依赖

- **操作系统**：Windows 10+ / macOS 10.14+ / Ubuntu 18.04+
- **Python 版本**：3.8+
- **硬件要求**：摄像头（用于隐私保护功能）、麦克风（可选，用于语音交互）。

## 项目结构

本项目遵循标准的 Python 工程化结构，资源与代码分离，便于维护。

```text
CubiclePal_MVP_v0/
├── main.py              # 主程序入口：负责初始化应用
├── start.py             # 简化启动脚本：一键启动应用
├── requirements.txt     # 依赖包清单：列出了所有第三方库
├── src/                 # 源代码核心模块
│   ├── ai/              # AI服务层：处理自然语言、对话逻辑
│   ├── core/            # 业务逻辑层：事务管理、出行规划算法
│   ├── ui/              # 用户界面层：宠物渲染、窗口管理
│   └── utils/           # 工具模块：通用辅助函数
├── resource/            # 静态资源
│   └── config.yaml      # 配置文件
├── data/                # 数据存储：用户任务数据、缓存
├── logs/                # 日志文件：运行日志记录
├── doc/                 # 项目文档：设计说明、API文档
└── test/                # 测试和演示脚本
```
