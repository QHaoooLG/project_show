本项目是一个高性能的**计算机视觉自动瞄准系统**，专为机器人竞赛（如 RoboMaster）或智能移动平台设计。系统集成了图像处理、目标检测、运动预测及云台控制算法，能够实现对动态目标的实时识别与锁定。

---

## 项目概述

在机器人对抗或自动化任务中，精准的视觉锁定是核心竞争力。本项目通过 C++ 实现了一套完整的视觉自瞄流水线，涵盖了从**图像采集**、**装甲板识别**、**弹道解算**到**云台控制**的全过程。

![](https://github.com/QHaoooLG/project_show/RM-QIQI-vision-main/哨兵机器人旋转靶自瞄.png)

### 核心亮点
- **实时性**：优化的图像处理流程，确保高帧率下的低延迟响应。
- **鲁棒性**：针对复杂光照环境（如逆光、阴影）进行了算法调优。
- **模块化设计**：代码结构清晰，易于移植和二次开发。

---

## 核心功能

### 1. 目标检测与识别
- **装甲板识别**：基于 OpenCV 的二值化与轮廓分析，精准提取灯条与数字区域。
- **分类算法**：利用 SVM 或深度学习模型（如有）区分敌我及不同编号的目标。

### 2. 运动预测与滤波
- **卡尔曼滤波 (Kalman Filter)**：消除目标坐标噪声，平滑运动轨迹。
- **运动模型预测**：针对匀速或匀加速目标进行弹道预测，解决“追尾”问题。

### 3. 坐标转换与解算
- **三维坐标解算**：利用 PnP 算法或三角测距计算目标距离。
- **云台控制**：输出 PID 控制指令，驱动云台电机追踪目标。

## 环境依赖与快速启动

### 环境要求
- **操作系统**：Ubuntu 22.04 LTS
- **核心库**：OpenCV 4.x, Eigen 3, CMake
- **硬件**：海康威视 (Hikvision) 工业相机 / USB 摄像头

### 快速启动
使用提供的启动脚本一键编译并运行系统。

```bash
# 1. 赋予执行权限
chmod +x start.sh

# 2. 运行启动脚本
./start.sh
```
