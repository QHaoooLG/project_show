## 📂 项目精选

### 1. 🎫 分布式景点门票预订系统 (IDEA_Ticketing)
> **核心标签**: `Java` `SpringBoot` `MyBatis` `MySQL` `后端开发`

一个基于 B/S 架构的网上景点门票管理平台，模拟了高并发场景下的票务处理流程。
- **主要功能**:
  - 实现了景点信息管理、门票库存动态管理、用户预订及订单生成核心业务。
  - 设计了基于数据库事务的库存扣减机制，防止超卖现象。
- **技术亮点**:
  - 采用 **SpringBoot + MyBatis** 快速构建后端服务，代码结构清晰，符合阿里巴巴开发规范。
  - 独立完成从数据库设计到 API 接口实现的全流程开发。
- **📂 [查看源码](./IDEA_Ticketing)**

### 2. 🤖 机器人装甲板自动瞄准系统 (Autoaim_deployment)
> **核心标签**: `C++` `ROS2` `OpenCV` `计算机视觉` `国家级奖项项目`

基于 ROS 2 分布式架构实现的机器人视觉自瞄系统，曾助力战队获得 **全国大学生机器人大赛一等奖**。
- **主要功能**:
  - 利用 **OpenCV** 进行图像预处理与装甲板特征提取。
  - 结合运动学模型计算目标距离与姿态，实现自动筛选最佳击打目标。
  - 通过 **Foxglove Studio** 进行仿真与实车数据闭环验证，优化击打参数。
- **🌟 开源贡献**:
  - 撰写并开源了 **《QIQI视觉避坑手册》** (`QIQI视觉避坑手册.pdf`)，累计 2 万字+，详细记录了部署流程、常见错误及调试技巧，用于战队技术传承。
- **🔗 原项目参考**: [rm_vision](https://github.com/chenjunnn/rm_vision)
- **📂 [查看部署文档与代码](./Autoaim_deployment)**

### 3. 🎮 图形化 Zoom 小游戏 (Qt_zoom)
> **核心标签**: `C++` `Qt` `面向对象` `游戏开发`

基于 Qt 框架进行的增量式游戏开发项目，展示了扎实的 C++ 面向对象编程能力。
- **主要功能**:
  - 实现了角色移动探索、攻击判定、死亡结算、道具收集等完整游戏循环。
  - 设计了随机道具生成算法，增加游戏可玩性。
- **技术亮点**:
  - 深入理解 Qt 信号槽机制与图形渲染流程。
  - 代码模块化程度高，便于后续功能扩展。
- **📂 [查看源码](./Qt_zoom)**

### 4. ✅ 核心算法模块自动化测试 (SoftwareTest)
> **核心标签**: `JUnit` `单元测试` `测试用例设计` `质量保证`

针对核心算法模块设计的标准化测试方案，体现了严谨的测试思维与自动化测试能力。
- **测试对象**:
  1. **排序算法模块**: 验证不同规模数据下的排序正确性与边界情况。
  2. **日期计算模块**: 验证“获取下一天日期”逻辑，覆盖闰年、月末、年末等复杂边界值。
- **工作内容**:
  - 运用 **等价类划分** 与 **边界值分析** 法设计测试用例。
  - 基于 **JUnit** 编写自动化测试脚本，生成可视化测试报告。
  - 成功发现并定位多个深层逻辑缺陷。
- **📂 [查看测试代码与报告](./SoftwareTest)**
