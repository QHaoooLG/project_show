#  Zork - 基于 Qt 的 Roguelike-RPG 游戏

[![Platform](https://img.shields.io/badge/platform-Qt%205.14%2B-blue)]()
[![Language](https://img.shields.io/badge/language-C%2B%2B17-orange)]()
[![License](https://img.shields.io/badge/license-MIT-green)]()

**Zork** 是一个由 C++ 和 Qt 框架构建的 Roguelike-RPG 游戏。玩家将扮演一名穿越到地牢世界的大学生，在充满随机道具和怪物的迷宫中生存、战斗并寻找回到现实的方法。

---

##  项目概述

在本项目中，我们通过面向对象的设计模式（OOP），构建了一个包含角色、怪物、道具和房间交互的完整游戏系统。项目不仅实现了基础的命令行逻辑，还利用 Qt 实现了图形化的交互界面（如战斗弹窗、游戏结束界面等）。

### 核心特性

- **多态道具系统**：武器、食物、学术物品拥有不同的属性加成。
- **动态战斗机制**：基于武力值对比的自动战斗与逃跑系统。
- **状态管理**：复杂的健康度、耐力值与背包重量计算系统。

---

## ️ 游戏机制

### 1. 角色状态 (Character Status)

角色拥有以下核心属性，需时刻关注以避免游戏结束：

- **生命值 (Health)**: 归零则游戏失败。
- **耐力值 (Stamina)**: 移动和战斗会消耗耐力，归零会影响行动。
- **武力值 (Weapon Sum)**: 决定战斗胜负的关键。
- **得分 (Score)**: 通过击败怪物和收集道具累积。

### 2. 战斗系统 (Combat System)

进入怪物房间会触发强制交互，玩家可选择 **讨伐 (Fight)** 或 **逃跑 (Run)**。

| 战斗结果     | 玩家武力值 > 怪物 | 玩家武力值 = 怪物      | 玩家武力值 < 怪物 |
| :----------- | :---------------- | :--------------------- | :---------------- |
| **胜负判定** | 玩家胜，怪物清除  | 玩家胜(斩杀)，怪物清除 | 玩家败，怪物存活  |
| **积分获取** | 1.0倍怪物积分     | 1.5倍怪物积分          | 无积分            |
| **耐力消耗** | 正常消耗          | 正常消耗               | 消耗降低 (x0.6)   |

> **逃跑机制**：无论武力值高低，逃跑均会扣除健康度，但能大幅降低耐力消耗 (x0.4)。

### 3. 道具系统 (Items)

道具效果会根据其稀有度（价值 1-10）进行动态加成。

- **食物类**：如 "鼠头鸭脖" (减益)、"烧烤" (增益)。
- **学术类**：如 "SCI一区论文" (大幅加分)、"导的压迫" (负面状态)。
- **武器类**：如 "罗技鼠标"、"燃烧的单片机"。
